Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 5 Oktober 2026 • sasanabersaudaraind.com

Kebijakan Privasi ini menjelaskan bagaimana PT. Sasana Bersaudara Indonesia ("SBI", "Perusahaan", "Kami") mengumpulkan, mengelola, melindungi, dan memperlakukan data pribadi pengguna situs web serta aplikasi portal sasanabersaudaraind.com.

1. Komitmen Kepatuhan Regulasi

Pengelolaan data pribadi di lingkungan SBI dilaksanakan dengan tunduk pada Undang-Undang Republik Indonesia Nomor 27 Tahun 2022 tentang Perlindungan Data Pribadi (UU PDP), regulasi Kementerian Ketenagakerjaan RI, serta ketentuan standar pengembang Google API Services User Data Policy.

2. Informasi yang Kami Proses

Dalam menjalankan fungsi manajemen ketenagakerjaan dan portal fasilitas, kami memproses kategori data berikut:

  • Data Akun & Identitas Pengguna: Nama lengkap, alamat surat elektronik (email), dan pengidentifikasi profil akun saat Anda masuk menggunakan Google Sign-In atau kredensial internal.
  • Data Operasional Fasilitas & Presensi: Bagi karyawan dan petugas lapangan yang menggunakan modul kehadiran kerja, data pencatatan waktu dan validasi titik koordinat operasional (bila diizinkan oleh perangkat).
  • Data Log Perangkat: Alamat IP, identitas peramban, stempel waktu interaksi, dan log audit keamanan sistem.

3. Kepatuhan Integrasi Google OAuth 2.0

Untuk mempermudah dan mengamankan autentikasi pengguna ke portal SBI:

  • Kami hanya mengakses cakupan izin minimum (minimum necessary scopes): openid, https://www.googleapis.com/auth/userinfo.email, dan https://www.googleapis.com/auth/userinfo.profile.
  • Data dari API Google digunakan semata-mata untuk verifikasi kredensial pengguna, menghubungkan akun ke status penugasan staf/klien, serta mencegah akses tidak sah.
  • Kepatuhan Persyaratan Limited Use: Penggunaan dan transfer data yang diterima dari Google API oleh PT. Sasana Bersaudara Indonesia ke aplikasi lainnya akan senantiasa mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

4. Kebijakan Anti Penjualan Data

PT. Sasana Bersaudara Indonesia tidak pernah dan tidak akan pernah menjual, menyewakan, memperdagangkan, atau memberikan data pribadi pengguna kepada pihak ketiga, pialang data, atau perusahaan periklanan dalam bentuk apa pun. Kami juga tidak memanfaatkan data pengguna untuk melatih model kecerdasan buatan generatif pihak ketiga.

5. Perlindungan & Penyimpanan Data

Data digital dilindungi dengan enkripsi transmisi TLS 1.3 dan pembatasan akses berbasis peran (Role-Based Access Control). Penyimpanan data dibatasi selama hubungan kerja sama atau akun pengguna aktif, dan akan dimusnahkan secara aman setelah masa retensi selesai.

6. Hak Pengguna & Penghapusan Akun

Pengguna berhak sewaktu-waktu meminta akses ke informasi pribadinya, meminta koreksi atas kekeliruan data, atau meminta penghapusan permanen data akun dari server kami.

Permohonan penghapusan data dapat disampaikan melalui surat elektronik ke: info@sasanabersaudaraind.com. Permohonan Anda akan diverifikasi dan diselesaikan dalam jangka waktu maksimal 3x24 jam kerja.
